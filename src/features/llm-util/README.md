# LLM utilities

Gemini API를 활용하는 LLM 기능을 기능 단위로 분리해 관리하는 영역입니다.

## 디렉터리 규칙

- `util-1/` ~ `util-4/`: 팀원별 또는 기능별 독립 작업 영역
- 각 util의 `index.ts`는 해당 작업 영역의 진입점입니다.
- 공통 호출·Mock·Gemini 응답 계약은 이 디렉터리의 루트 모듈에서 관리합니다.
- util 간 공통 코드가 필요해지는 시점에 별도 공통 모듈 위치와 의존 방향을 합의합니다.
- API 키와 기타 비밀값은 저장소에 커밋하지 않습니다.

개발자 모드(`/developer-test`)에서 각 기능을 선택해 호출 흐름을 확인할 수 있습니다. 기본값은 Mock이며, 실제 Gemini 호출은 서버 전용 개발 프록시를 사용합니다.
