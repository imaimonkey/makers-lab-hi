# 0723 통합 브랜치 작업 기록

기준 브랜치: `0721-backup`

통합 브랜치: `0723-backup`

## 통합 원칙

`0721-backup`은 공통 레이아웃·라우팅·도메인 데이터 계약을 제공하고, `0723-backup`은 네 기능 브랜치의 고유 상호작용과 업무 화면을 현재 경로에 포팅한다. 원격 브랜치의 오래된 `room-*` 셸과 전역 스타일은 복사하지 않고, 그 안의 기능을 현재 조합 계층·feature 계층·공식 디자인 토큰으로 재구성했다.

| 원격 기능 브랜치 | 현재 통합 경로 | 반영 상태 | 운영 전환 의존성 |
| --- | --- | --- | --- |
| `origin/hyoje` | 대시보드 `/`, 탐색 `/risks`, 상세·평가 `/risks/:riskId` | 5채널·프로세스·이슈 매트릭스·준비도·시장/법령/상품 설계, 수집/본문/AI/검증 큐, 기사 원문·사실/해석·근거·불확실성·독립 출처·5단계 게이트, 9항목 종합평가와 이력까지 반영 | 뉴스·법령·상품·평가 API의 운영 서버, 재시도/권한/감사 로그 |
| `origin/seoyeon` | 탐색 `/risks` | 6개 분류, 기간·지역·정렬·검색, 법률 4건과 판례/손해/시장 신호 4건, TOP-5 12열 비교, 5개 후보의 8개 지표별 분석 근거·출처·판단 팝오버 반영 | 공식 통계·법령 원문, 요율화 모델, 비교 결과 저장 |
| `origin/jh` | 리포트 `/reports` | 리포트 목록·신규 생성·단계 로딩·검증/fallback, 상세 편집·서버 저장, 12개 상품화 평가, 약관 초안·Q&A·PDF를 반영. same-origin 프록시는 생성/약관/Q&A/조회/저장 5개 액션 지원 | `VITE_POTENS_PROXY_URL`, GAS 또는 서버 구현, SSO/RBAC, 감사 로그 |
| `origin/sh` | 상세 `/risks/:riskId` | 역할 탭, 검토/PDF/저장/공유, 4개 핵심 통계, 3축 위험 드라이버, 8개월 추세와 차트/표 전환, 추세 요약, 근거 필터, 우선 대응 3건, 판단 메모·체크리스트 반영 | 실제 근거 ID 원장, 외부 원문 URL 검증, 권한별 저장 API |

## 안정 경로·테마 확인

- `/`, `/risks`, `/risks/:riskId`, `/reports`, `/customer-insight` 경로를 유지했다.
- `/customer-insight`는 `CustomerLayout`, 실무자 상세는 `RootLayout` 아래에 둔다.
- 페이지는 조합 계층으로 유지하고 hyoje·seoyeon·sh 기능은 `src/features`, 공유 데이터 계약은 `src/domain`, jh 리포트 엔진은 `src/report`에 유지했다.
- 모든 새 수치·추이·검토 제안은 `SAMPLE` 또는 샘플 문구를 유지한다. 보험료·보장·가입 가능 여부를 단정하지 않는다.

## 검증

최종 커밋 전 `npm run check`, `git diff --check`, 안정 경로 확인을 실행한다. Vite의 500 kB 초과 번들 advisory는 기존 리포트 슬라이스 크기에 따른 경고이며 빌드 실패가 아니다.

## 다음 의존성

운영 연결 시 hyoje 위험 파이프라인 API와 jh 리포트 프록시의 인증·권한·감사 경계를 서버에 구현하고, 상세 메모·체크리스트·평가 이력을 권한 검증 저장소로 교체한다. 각 판단 문장에 `evidenceId`, 불확실성, 반증 또는 보류 이유를 연결한다. 단일 고객 신호나 샘플 점수는 후보 확정 근거로 사용하지 않는다.
