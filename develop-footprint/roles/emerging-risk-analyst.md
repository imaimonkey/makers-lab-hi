# 신규위험 탐색 실무자

## 역할 목표

산업·기술·사회·기후 변화에서 보험 손실로 이어질 수 있는 변화를 조기에 발견하고, 충분한 근거가 있는 후보만 상품 검토 단계로 넘긴다. 속도뿐 아니라 판단의 재현성, 반증 가능성, 규제·소비자보호 검토 가능성이 중요하다.

## 핵심 질문

1. 무엇이 변했고, 변화 속도는 이전 관측보다 빨라졌는가?
2. 누가 어떤 사건으로 경제적 손실을 입는가?
3. 기존 상품·특약·인수 기준으로 다룰 수 있는가?
4. 보장 공백은 실제 고객 문제인가, 단순한 정보 부족인가?
5. 데이터로 빈도·심도·상관·역선택 가능성을 추정할 수 있는가?
6. 지금 `진행`, `보류`, `종료` 중 어떤 결정이 타당하며 무엇을 더 확인해야 하는가?

## 대표 작업 흐름

```text
외부·내부 신호 확인
  → 중복 제거·출처 검증
  → 위험 후보 정규화
  → 손실사건과 노출집단 정의
  → 기존 보장·상품 적합성 분리 평가
  → 근거와 반증 검토
  → 진행/보류/종료 결정
  → 승인 가능한 리포트
```

## 사용성 기준

- 첫 화면에서 `어제와 달라진 것`, `조치가 필요한 것`, `데이터가 끊긴 것`을 구분한다.
- 기사 개수 대신 독립 출처 수, 최신성, 변화 속도, 반증을 보여준다.
- 신호 강도와 상품화 적합성을 하나의 종합 점수로 숨기지 않는다.
- 모든 판단에는 담당자, 갱신 시각, 근거 ID, 다음 조치가 따라야 한다.
- 고객 신호는 원문이 아니라 최소 집계된 패턴과 범주로만 본다.
- 고위험 결정은 자동화가 아니라 사람이 근거를 확인하고 승인한다.

## 성공 지표 후보

- 후보 생성부터 1차 분류까지의 시간
- 후보별 독립 근거·반증 비율
- 보류 후 재검토 기한 준수율
- 상품 검토 단계로 진입한 후보의 근거 완결성
- 중복 후보 감소율과 감사 로그 완전성

지표를 구현 성과로 고정하기 전에 실제 업무 베이스라인과 데이터 가용성을 확인해야 한다.
