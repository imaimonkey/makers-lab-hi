# 위험 후보 카드별 기사 분석 프롬프트

2026-07-30 기준으로 `/risks` 위험 후보 화면의 기사 분석용 시스템 프롬프트를 카드 섹션별로 분리했다.

런타임 프롬프트는 [data/system-prompts/step2 디렉터리](../../data/system-prompts/step2/)에서 읽으며, 후보 기본 정보·위험 및 상품화 개요·시장성/우연성/법률 및 규제 리스크/PML 예비 수치화·법령 트래킹 목록/상세·법령 상세의 판례/손해 탭·기사 큐·상품개발 후보·추세를 각각 독립 출력한다. 4개 수치화는 종합 리포트의 `상품화 종합 평가`와 같은 시장성·우연성·법률 및 규제 리스크·PML 기준을 사용하며, 기존 8개 지표는 카드의 근거·점수 계산을 위한 내부 계약으로 유지한다. 검색·필터·API 상태·업무 단계 숫자는 기사 LLM이 추정하지 않고 애플리케이션 또는 서버가 관리한다.

현재 화면은 SAMPLE·검토용 프레임이므로, 실제 운영 연결 전에는 JSON schema 검증, canonical 근거 ID 매핑, 중복 출처 제거, 최신성 확인, 개인정보 검사, 사람의 후보 검토 게이트가 필요하다.
