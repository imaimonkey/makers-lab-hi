# 위험 후보 02 · 신규 위험 타당성 스크리닝

기존 8개 비교표 대신 카드 안에 `시장성`, `우연성`, `법률 및 규제 리스크`, `PML`을 표시한다. 각 지표는 종합 리포트의 `상품화 종합 평가`와 같은 기준으로 산정하며, 버튼 상세 패널에서 공식·공개 입력, 프로젝트 가정값, 산식, 결과를 보여줄 수 있어야 한다.

각 지표의 출력 필드:

```json
{"label":"시장성","value":"기사 기반 수요 신호","sub":"기사 기반 · SAMPLE","color":"orange","official":[],"assumption":["공개 시장자료 미연결"],"formula":["1차 검토값 표시"],"result":"확인 필요","numericValue":null,"unit":"","confidence":"기사 기반","isSample":true,"evidenceIds":[]}
```

- `market`은 기사 수요·확산 신호의 대리지표다.
- `fortuity`는 사고가 우연하고 사전에 통제되지 않는지, 계약 전 발생·고의 손해와 구분되는지 검토한다.
- `legalExposure`는 법률 및 규제 노출, 책임주체의 명확성, 약관·보장조건 확인 필요성을 검토하며 법적 결론을 확정하지 않는다.
- `pml`은 손실 분포·집적 범위가 없으면 임의 산정하지 않는다.
- 시장성은 성장성·실제 수요·제도 필요성·상품화 검증·구매 접근성을, 우연성은 우연한 사고 가능성·사전 통제 여부·고의성 구분을 기준으로 한다.
- 법률 및 규제 리스크는 법률·규제 노출 수준·책임주체 명확성·약관·보장조건 확인 필요성을, PML은 단일사고·누적·시설/긴급대응 손해를 기준으로 한다.
- 상품화 종합평가에 연결할 근거가 없으면 다른 기준으로 대체하지 말고 `확인 필요`·`계산 보류`로 표시한다.
- 화면 숫자는 상품 승인·보험료·손해율·가입 가능성을 뜻하지 않는다.
