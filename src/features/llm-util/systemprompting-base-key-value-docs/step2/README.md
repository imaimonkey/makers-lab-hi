# Step 2 · 위험 후보 카드별 시스템 프롬프트

런타임 기준 프롬프트는 `data/system-prompts/step2`에 있다. 이 디렉터리는 카드 섹션별 설계와 출력 계약을 추적하기 위한 개발 문서다.

`주요 법률 및 규제 업데이트`는 기존 동일 기준 비교표 대신 후보별 세로형 카드로 구성한다.

- `01-risk-candidate-card.md`: 후보 기본 정보, 위험 및 상품화 개요, 점수, 다음 검토
- `02-screening-metrics-card.md`: 시장성·우연성·법률 및 규제 리스크·PML 4개 예비 수치화와 상세 산식
- `03-law-regulation-card.md`: 주요 부처별 최신 법률·규제
- `04-case-loss-market-card.md`: 연관 판례·실제 손해·시장 이슈
- `05`~`07`: 기사 분석 큐, 후보 검토, 신호 추세

모든 출력은 기사 근거와 AI 추정을 구분하고, 입력에 없는 숫자·법적 결론·보험 상품 결론을 만들지 않는다. 근거가 없으면 `확인 필요` 또는 `계산 보류`를 사용한다.
