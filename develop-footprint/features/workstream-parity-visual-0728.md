# 0728 수직 브랜치 화면 parity 보완

## 목적

`otherstatus/`의 기능 계약만 복사하지 않고, 각 브랜치가 세로로 구성한 화면 구조·스타일·세부 상호작용을 루트의 안정 경로에 맞춰 반영한다.

## 반영 내용

- `jh` `/reports`: 최신 브랜치와 같은 7개 상단 탭 순서와 라벨을 사용한다. 목록 전용 안내 영역은 상세 탭 위를 밀지 않도록 분리했고, 실무자 메모는 브리핑 내부 보조 영역으로 보존했다.
- `jh` 상품화 평가: 평가 항목의 연동 출처에서 관련 리포트 탭으로 이동할 수 있다. 실무자 입력 변경은 기존 AI 결과를 자동 덮어쓰지 않고 저장 전 경고로 표시한다.
- `hyoje` `/risks`: API 재조회·부분 실패 상태·SAMPLE fallback을 유지하면서 후보 탐색 화면에 키워드/법령/기사 큐와 신호 추세 시각화를 함께 제공한다. 후보 등록은 canonical 상세 ID가 매핑될 때만 이동한다.
- `hyoje` `/risks/:riskId`: 연결된 기사 상세 API의 본문·분석·검증 상태를 상세 화면에 표시하고, 액션 성공 후 재조회한다. 매핑 없는 위험은 다른 기사의 근거를 재사용하지 않는다.
- `seoyeon` `/risks`: TOP-10 비교표의 점수 표현에 도트·진행률·법적 위험 하위 설명·태그별 색상·근거 tooltip을 반영했다.
- `sh` `/risks/:riskId`: 목록 복귀·상태·근거 이동·PDF 명령 바, canonical 위험 ID와 breadcrumb/meta, grid 배경 및 violet accent를 상세 화면 범위로 적용했다.

## 경계

- 루트의 `RootLayout`, 고객 `CustomerLayout`, 안정 경로와 공통 Hi 색상 토큰은 유지한다.
- API가 없는 데이터는 `LIVE API`, `SAMPLE fallback`, `확인 대기`를 구분한다.
- 재분석 API가 연결되지 않은 상태에서는 변경된 입력을 자동 반영하지 않으며, 사용자가 저장·검토하도록 둔다.
- PII, 보험료, 가입 가능 여부, 보장 확정 문구는 추가하지 않는다.
