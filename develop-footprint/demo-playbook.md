# 발표·데모 플레이북

## 권장 3분 시나리오

1. `/` 실무자 화면에서 위험 레이더와 `고객 인사이트 유입 0건`을 보여준다.
2. 우상단 `개인고객`을 눌러 완전히 다른 공개 웹 화면으로 전환한다.
3. `데모 예시 준비하기`를 눌러 ESS·스마트홈 상황을 채우고 `내 상황 분석하기`를 실행한다.
4. 관련 상품 후보 3개와 약관 확인 포인트를 먼저 보여준다.
5. `새롭게 살펴볼 생활 위험`에서 기존 상품 설명의 빈틈을 보여준다.
6. 선택 동의가 체크된 상태에서 `개인정보 없이 연구 의견 보내기`를 누른다.
7. 우상단 `실무자`로 돌아가 유입 건수와 비식별 고객 신호가 갱신된 것을 보여준다.

이 순서는 고객 추천 기능 자체보다 `기존 상품 탐색 → 미충족 위험 발견 → 실무자 연구 신호 환류`라는 제품의 차별점을 보여준다.

## 발표 전 준비

- `npm run dev`로 앱을 실행한다.
- 실무자 대시보드 고객 큐에 데이터가 있으면 `데모 큐 비우기`를 누른다.
- 브라우저 확대율을 100%로 맞춘다.
- 공식 상품 외부 링크는 발표 네트워크에서 열리는지 미리 확인한다.
- 결과가 공식 추천·보장 확정이 아닌 콘셉트라는 고지를 생략하지 않는다.

## 화면 전환 원칙

- 고객 앱은 실무자 좌측 메뉴에 없다.
- 두 화면은 우상단 `실무자 / 개인고객` 전환만 공유한다.
- 데모에서는 고객 원문이 아니라 비식별 요약만 실무자 큐에 나타나는 점을 짚는다.
- 운영 서비스에서는 두 채널의 배포·인증·저장소를 분리하고 집계 신호 API만 연결한다.
