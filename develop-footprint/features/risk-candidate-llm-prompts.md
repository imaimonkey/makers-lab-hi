# 위험 후보 카드별 기사 분석 프롬프트

2026-07-28 기준으로 `/risks` 위험 후보 화면의 기사 분석용 시스템 프롬프트를 카드 섹션별로 분리했다.

프롬프트는 [step2 디렉터리](../../src/features/llm-util/systemprompting-base-key-value-docs/step2/)에 있으며, 후보 기본 정보·8개 지표·법률·판례/손해·기사 큐·상품개발 후보·추세를 각각 독립 출력한다. 검색·필터·API 상태·업무 단계 숫자는 기사 LLM이 추정하지 않고 애플리케이션 또는 서버가 관리한다.

현재 화면은 SAMPLE·검토용 프레임이므로, 실제 운영 연결 전에는 JSON schema 검증, canonical 근거 ID 매핑, 중복 출처 제거, 최신성 확인, 개인정보 검사, 사람의 후보 검토 게이트가 필요하다.
